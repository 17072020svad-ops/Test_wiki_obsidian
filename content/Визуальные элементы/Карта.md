# Карта

#Карта (Map)
**Тип:** Географический анализ
**Сложность:** ⭐⭐ Средний

## 📋 Когда использовать
- Показать данные в разрезе географии
- Сравнить показатели по регионам, городам, странам
- Например: продажи по регионам России на карте

## 🛠️ Как добавить в Power BI
1. На панели визуализаций нажми иконку карты (или карты с фигурами)
2. В поле **Расположение** перетащи географический столбец (Город, Регион, Страна)
3. В поле **Размер пузырька** перетащи числовой столбец (например, Продажи)
4. В поле **Легенда** — добавь категорию для цветового разделения

## ⚠️ Важно знать
- Power BI автоматически определяет координаты по названию города или региона
- Если город не распознаётся — добавь столбец со страной для уточнения
- Названия городов лучше писать на английском — распознаются точнее
- Для карты нужно включить геоданные в настройках Power BI Desktop

## ⚙️ Полезные настройки
- **Пузырьки vs Фигуры** — пузырьки для точек, фигуры для закрашивания регионов
- **Цветовое насыщение** — чем темнее цвет тем больше значение
- **Всплывающие подсказки** — настрой что показывать при наведении мыши
- **Детализация** — можно настроить переход Страна → Регион → Город
