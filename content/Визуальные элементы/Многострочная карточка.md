# Многострочная карточка

#Многострочная-карточка (Multi-row Card)
**Тип:** Несколько ключевых чисел
**Сложность:** ⭐ Начальный

## 📋 Когда использовать
- Показать сразу несколько метрик в компактном виде
- Сводка показателей по одному объекту
- Например: по каждому региону — Выручка, Количество сделок, Средний чек

## 🛠️ Как добавить в Power BI
1. На панели визуализаций нажми иконку многострочной карточки
2. В поле **Поля** перетащи несколько мер по очереди
3. Каждая мера отобразится отдельной строкой с подписью

## ⚠️ Важно знать
- При наличии категории в фильтре — карточка покажет значения для каждой категории
- Не добавляй больше 5-6 полей — карточка станет громоздкой
- Лучше использовать меры DAX для точных расчётов

## ⚙️ Полезные настройки
- **Метки данных** — измени названия на понятные пользователю
- **Единицы отображения** — тысячи или миллионы для больших чисел
- **Количество столбцов карточек** — сколько карточек в одной строке
- **Фон** — добавь цвет для выделения блока метрик
