# Матрица

#Матрица (Matrix)
**Тип:** Сводные данные
**Сложность:** ⭐⭐ Средний

## 📋 Когда использовать
- Сводная таблица с группировкой по строкам и столбцам
- Когда нужно сравнить показатели по двум измерениям сразу
- Например: продажи по Регионам (строки) и Месяцам (столбцы)

## 🛠️ Как добавить в Power BI
1. На панели визуализаций нажми иконку матрицы
2. В поле **Строки** перетащи первую категорию (например, Регион)
3. В поле **Столбцы** перетащи вторую категорию (например, Месяц)
4. В поле **Значения** перетащи числовой столбец (например, Продажи)

## ⚠️ Важно знать
- Матрица поддерживает иерархию — можно раскрывать уровни (Год → Квартал → Месяц)
- При большом количестве столбцов появится горизонтальная прокрутка
- Итоги считаются автоматически по строкам и столбцам

## ⚙️ Полезные настройки
- **Условное форматирование** — тепловая карта прямо в таблице
- **Развернуть всё** — показать все уровни иерархии сразу
- **Итоги строк/столбцов** — включи или выключи по необходимости
- **Ступенчатый макет** — вложенные категории отображаются с отступом
