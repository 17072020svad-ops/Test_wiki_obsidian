# Таблица

#Таблица (Table)
**Тип:** Детальные данные
**Сложность:** ⭐ Начальный

## 📋 Когда использовать
- Показать детальные данные по каждой строке
- Когда пользователю нужны точные числа а не тренды
- Например: список всех сделок с суммами и датами

## 🛠️ Как добавить в Power BI
1. На панели визуализаций нажми иконку таблицы
2. В поле **Столбцы** перетащи нужные поля по очереди
3. Порядок столбцов меняется перетаскиванием прямо в поле

## ⚠️ Важно знать
- Таблица показывает ВСЕ строки — при большом объёме тормозит отчёт
- Не добавляй больше 6-7 столбцов — станет нечитаемо
- Для сводных данных лучше подойдёт Матрица

## ⚙️ Полезные настройки
- **Условное форматирование** — закрась
