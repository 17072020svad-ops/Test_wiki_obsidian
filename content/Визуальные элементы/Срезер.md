# Срезер

#Срезер (Slicer)
**Тип:** Фильтрация
**Сложность:** ⭐ Начальный

## 📋 Когда использовать
- Дать пользователю возможность фильтровать отчёт кнопками
- Выбор периода, региона, категории товара
- Например: кнопки "2022 / 2023 / 2024" для фильтрации по году

## 🛠️ Как добавить в Power BI
1. На панели визуализаций нажми иконку срезера
2. В поле **Поле** перетащи категорию по которой будет фильтрация
3. Выбери стиль отображения — список, кнопки или выпадающий список

## ⚠️ Важно знать
- Срезер фильтрует ВСЕ визуалы на странице одновременно
- Можно настроить чтобы фильтровал только определённые визуалы
- Для дат лучше использовать срезер с ползунком — удобнее для пользователя

## ⚙️ Полезные настройки
- **Стиль → Кнопки** — красиво если категорий мало (до 5)
- **Стиль → Выпадающий список** — экономит место если категорий много
- **Выбор нескольких значений** — позволяет выбрать сразу несколько пунктов
- **Синхронизация срезеров** — один срезер может фильтровать несколько страниц отчёта
