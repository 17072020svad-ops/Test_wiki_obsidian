# Линейчатая диаграмма

#Линейчатая-диаграмма (Line Chart)
**Тип:** Тренды и динамика
**Сложность:** ⭐ Начальный

## 📋 Когда использовать
- Показать изменение значений во времени
- Сравнить несколько показателей на одном графике
- Например: динамика продаж по месяцам за год

## 🛠️ Как добавить в Power BI
1. На панели визуализаций нажми иконку линейчатой диаграммы
2. В поле **Ось X** перетащи дату или период (например, Календарь[Месяц])
3. В поле **Значения** перетащи числовой столбец (например, Продажи[Сумма])
4. В поле **Легенда** — добавь категорию если нужно сравнить несколько линий

## ⚠️ Важно знать
- Лучший выбор для временных рядов — не используй гистограмму для дат
- Не добавляй больше 4-5 линий — график станет нечитаемым
- Включи маркеры точек чтобы видеть конкретные значения

## ⚙️ Полезные настройки
- **Маркеры** — включи чтобы видеть точки на линии
- **Линия прогноза** — Power BI может автоматически продлить тренд
- **Область под линией** — включи для визуального акцента
- **Подписи данных** — показывает значения прямо на графике
