# AVERAGE

#AVERAGE (Mean Value)
**Категория:** Агрегация
**Сложность:** ⭐ Начальный

## 📋 Краткое описание
Считает среднее арифметическое всех чисел в столбце.

## 📝 Синтаксис
`AVERAGE(<столбец>)`

## 💡 Пример
`Средний чек = AVERAGE(Продажи[Сумма])`

## ⚠️ Важно
- Игнорирует пустые ячейки
- Для среднего с условием используй AVERAGEX
- Чувствителен к выбросам — большие значения искажают результат
